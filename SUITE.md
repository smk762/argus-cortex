# The Argus suite: map for agents

The canonical list of every Argus repo: what each one is for, and which one already does the thing you are about to build.
Every repo's `CLAUDE.md` imports this file. **Before designing a feature, check the "Need it? Use it" index.** If a
sibling already does it, call that sibling (HTTP, or its library) instead of rebuilding it.

**Keep it current. Every release of any Argus repo checks its row here.** If a release adds, removes or renames a
capability, endpoint, port, UI pairing or dependency, open a PR to `argus-cortex` that updates this file in the same
release. A new repo adds a row and the import block (see the end of this file) before its first release.

**How they fit.** The LoRA pipeline is `quarry → curator → lens → forge → (trainer) → proof → atlas`; curator, lens,
forge and proof carry the same `TargetProfile` from cortex. Darkroom is the suite's way to generate an image: mint
renders through it, and anything new that needs a picture (mask backgrounds, game art) should too. Proof's sample grids
and atlas's bakes predate it and still drive their own diffusion backend. Survey stands alone; its GeoTIFFs can feed
atlas. Retina serves the small detectors (NudeNet, EraX, watermark, OCR) the stages call over HTTP. Every Python
service except retina depends on cortex. UIs are thin clients: the service decides and the UI only
shows.

**API and UI pairs.** darkroom ↔ safelight · curator ↔ cull · lens ↔ lightbox · survey ↔ sightline · mint ↔ assay.
Studio has a page for lens, curator, quarry, forge, proof, atlas and darkroom, and links out to sightline, mask and assay.

## Need it? Use it

| Need | Use | Don't |
|---|---|---|
| Generate an image (a plate, a background, art, a sample), or rework or inpaint one | **darkroom** `POST /generate/stream` (SSE; `init_image`, with `mask_base64` to inpaint), `GET /image/{id}`. Its record id, model and seed are your provenance. Send `X-Argus-Priority: batch` for background work (sample runs, libraries) so a person's render goes first. Example client: mint's `DarkroomClient`. | Call ComfyUI directly or generate without checks. |
| Check an image for nudity, or text/an image against a policy | `argus_cortex.moderation` (`NudeNetClient`, `SingGuardClient`, `policies`). Point `NudeNetClient` at **retina**'s `argus-retina-nudenet` (640m); `info()` says which model a server runs. | Write your own nudity definition or policy text, or run your own NudeNet server (the upstream image is 320n). |
| Read the text in an image (check a name or quote a caption claims) | **retina** `argus-retina-ocr`: one detection per line with its `text`, in reading order, read through cortex's `OcrClient`. Check a claim with `OcrResult.contains`, which compares without case, spaces or punctuation, since words can run together | Ask a VLM to transcribe, or load Florence-2 in-process: both write plausible text that isn't there. |
| Detect watermarks, or a second nudity opinion (EraX) | **retina** `argus-retina-watermark` (mount the YOLO11x; curator's `crops.detect` calls it) or `argus-retina-erax`, both on NudeNet's `POST /infer` shape | Bake an unlicensed model into an image, or run a detector inside your stage. |
| Share the GPU with other services | `argus_cortex.gpu` (`coordinator_from_env()`, `lease()`/`alease()`); `ARGUS_GPU_COORDINATOR=broker` asks argus-iris, which places, prioritises and makes room across nodes. Declare your GPU use in a committed `gpu-tenant.yaml` (`gpu-tenant-schema.json`). | Assume the GPU is free, or keep your own idle-unload or keep-alive policy. |
| Let the GPU broker unload and reload your model | The resident contract (echo, voluptas and agent-composer serve it): `GET /health` answering cortex's `ResidentHealth` (top-level `model_state`, `busy`, `idle_s`; a memory-only `gpu` block); `POST /admin/unload` (VRAM and RAM), `/admin/evict` (GPU to CPU), `/admin/wake`, answering `ResidentActionReply`, or 409 `ResidentBusyReply` while busy, behind `Authorization: Bearer $ARGUS_ADMIN_TOKEN` when set. List the model as a resident in `gpu-tenant.yaml` (`health_path`, `unload_path`, `evict_path`, `warm_path`, `admin_auth`). Non-Python services: `gpu-resident-schema.json`. | Invent your own lifecycle routes or an idle timer iris cannot see. |
| Call a local or hosted model | `argus_cortex.backends` (`LocalBackend`, `RemoteBackend`, `with_retries`) | Hand-roll an HTTP client per model. |
| Version a wire payload, commit its schema | `argus_cortex.wire` (`make_versioned_base`, `render_schema`) | Ship an unversioned contract. |
| Guard a FastAPI server's writes, or run read-only | `argus_cortex.server` (`WriteGuard`, `env_flag`) | Use `BaseHTTPMiddleware`, which buffers streams. |
| Join a path from a request, manifest or archive onto a directory; use an id or an upload's filename as a file name | `argus_cortex.fs` (`safe_join`, `safe_name`, `safe_basename`; refuses with `PathRefused`) | Hand-roll a `..` check, check one spelling and open another, use `re.match` with `$`, or trust `Path(upload.filename).name`. |
| Fetch a URL that came from a request, a manifest or another service | `argus_cortex.net` (`fetch` / `afetch`; `allow_hosts` for internal services by name) | Call `httpx`/`requests` on it directly, check only the hostname, or follow redirects automatically. |
| Protect an admin route with a token | `argus_cortex.auth` (`Depends(bearer("ARGUS_ADMIN_TOKEN"))`; `open_when_unset=True` only where open-in-dev is intended) | Compare tokens with `==`, or leave the route open when the variable is unset without saying so. |
| Read a request body, an upload, base64 or an image from a client | `argus_cortex.limits` (`read_body`, `read_upload`, `decode_base64`, `open_image`) | `await request.body()`, `await upload.read()`, decode base64 before checking its length, or rely on Pillow's default pixel limit. |
| Read or write XMP sidecars | `argus_cortex.xmp` | Overwrite another stage's properties. |
| Record lineage, embeddings or blobs | `argus_cortex.store` (`open_lineage_store` / `open_vector_store` / `open_blob_store`) | Add a database to a single stage. |
| Record where a face, voice or image came from, or whether it may be shown publicly | `argus_cortex.provenance` (`Provenance`, `.cleared`, `generator`); non-Python clients use `provenance-schema.json` | Define your own provenance kinds or consent fields. |
| Check a real person's consent for a use of their face or voice | `argus_cortex.consent` (`ConsentRecord`, `consent_valid` → `ConsentVerdict`, `consent_matches`); non-Python clients use `consent-schema.json`. Records are written by **mask** | Invent refusal reasons, or serve a record (it names a person). |
| The training target (style, category) | `argus_cortex.taxonomy`; non-Python clients use `taxonomy-schema.json` | Copy the literals. |
| Acquire source photos with licence and provenance | **quarry** (`quarry export` publishes each photo with a `<stem>.json` provenance sidecar) | Scrape inside another stage. |

## Shared rules

Suite-level checks are argus-ci's `suite-rules.yml` rules (`@v1`, in every repo that runs the job). A rule that can't be a
lint rule says which tests hold it instead (argus-ci#19).

| Rule | Enforced by |
|---|---|
| Shared code lives in cortex: import it, don't copy it. A cortex change ripples into every stage on its next bump. | argus-ci suite rule `cortex-copy` (convention): no local `safe_join`, `safe_name`, `env_flag`, `WriteGuard` or `DEFAULT_EXPOSED_LABELS` |
| Provenance first. Anything the suite serves or trains on carries its source and licence; unlicensed input is refused. | Per repo (quarry, curator, mask). Not a lint rule: what counts as provenance is per repo (argus-ci#19) |
| Optional heavy dependencies are lazy imports behind extras. | In cortex only (`test_rules::test_top_level_import_loads_no_optional_extra`); **UNENFORCED** suite-wide. Not a lint rule (it needs the repo's extras); the check is a per-repo base-deps import test (argus-ci#19) |
| A missing service config fails open to a no-op, never a crash. | In cortex only (the `open_*_store` tests); **UNENFORCED** suite-wide. Not a lint rule: the same early return is right for a cache and wrong for a gate, so it's per-repo tests (argus-ci#19) |
| Talk across repos over HTTP or a versioned wire schema, never by reading another repo's files. | argus-ci suite rule `sibling-checkout-read` (convention): no path into a sibling checkout (`../argus-x`, `/home/<user>/argus-x`, `.parent / "argus-x"`) |
| Never import NudeNet (AGPL-3.0); call a server over HTTP. | argus-ci suite rule `agpl-import` (nudenet and ultralytics, `importlib` included); cortex also bans it with ruff `TID251` |
